BL-346 · open-world grid · sketch

Vardelar World Grid

"I want the map to be in a grid order with 50k x 50k in cells .. and each cell to be its own zone, several zones can be a castle territory ... a real open world map."

The server is already one seamless world: one coordinate space, 3,000-unit interest cells streamed around you, no map loads. So the grid is a data job, not a new engine. This page has two parts: today's world drawn under a grid, so the cell size can be chosen by eye, and a board where you lay cells out like puzzle pieces.

Read off the code: 6 towns (Towns.cs), 31 generated fields (WorldPlan), 3 hand-placed areas. Field boxes are their bounds, coloured by Biomes.cs. Dungeons live in the negative quadrant and are left out.

My recommendation: 25k per cell

At 50k one cell is bigger than everything built so far, so a territory of several cells means authoring several of today's worlds before it feels filled. At 25k one city and its fields is about one cell, a castle territory of 2 to 4 cells is reachable, and crossing a cell still takes over a minute and a half on foot. 12.5k cuts the cities in pieces. The board below only stores grid positions, so this choice can change later without redrawing it.

2 · the puzzle board

Lay out the cells

Click a + next to a cell to add a piece, click a cell to edit it. Borders between two cells are open (the biomes blend), a passage (a wall with a gap, like your lava-to-snow pass) or a wall. Cells with the same territory name share an outline colour. What you change is saved for both of us; I read it back when we build.

Select a cell to edit it, or a + to add one.

3 · what a cell becomes in code

From board to game

On the boardIn the game
Cell + nameA zone id over a square of the world; teleports and the map window name it.
BiomeThe ground colour. Biomes.cs moves onto the cell; the client's ground already blends neighbours.
LevelsThe band its fields are planned for. WorldPlan places fields by bearing and distance from their city, so moving a city moves its fields.
TerritoryThe castle that owns these cells, ready for castles and the vault.
Wall / passageGameplay, not paint: the server needs movement collision and mob pathing around them. This is the one genuinely new system.
Start flagBL-349's race starting zones: each race spawns in its own territory.
